# FLAGSHIP COURSE — Task Analysis, Cognitive Engineering & Design Validation for Aerospace HSI

**Revision:** 1.0 candidate | **Created:** 2026-10-09 | **Type:** graduate / practicing-engineer independent course | **State:** instructional content implemented; not externally peer-reviewed or approved for any employer's procedure.

## Thesis
The design unit is **not a screen, button, or task list**. It is an **operator's constrained pursuit of an operational goal inside a human–automation control system**. Correct analysis must reveal the goals, task plans, decisions, expert cues, information quality, control authority, source states, uncertainties, recovery paths, and measures that establish actual operational success.

The throughline is: **mission → scenario → work constraints → functions → task plan → cognitive decisions → information/control needs → architecture → requirements → concept alternatives → evaluation claim → valid operational measures → evidence → standardized engineering method**.

## Audience
PhD-level human-factors/cognitive psychology and early/mid-career aerospace HSE/SE practitioner. Assumes experimental-design fluency but **does not** assume expertise in CTA, CWA, aviation data/system architecture, STPA, systems engineering, procedure engineering, or applied requirements.

## Use in 3 modes
- **Deep study (5–7 h/week):** lecture, research reading, worked problem, applied lab, review and retrieval. Sixteen weeks.
- **Accelerated engineer (2 h/week):** lecture + one minimum deliverable. Sixteen weeks; no mastery claim.
- **Instructor/peer-cohort:** add calibration, paired cross-review, SME interview protocols and capstone defense.
