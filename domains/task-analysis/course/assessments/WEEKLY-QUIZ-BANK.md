# Weekly quick assessments (16 x 3)

These are conceptual retrieval questions; lessons also include case-specific questions. Do before reviewing the lesson, then self-score using primary texts and a peer when possible. A correct answer requires an argument, not merely an acronym.

| Week | Recall | Apply | Critique |
|---:|---|---|---|
| 1 | Define decision vs task | Classify selected/active | Identify design-first bias |
| 2 | Describe MEM | Choose five scenarios | Explain why full matrix may be invalid |
| 3 | Explain HTA plans | Write conditional recovery plan | Find missing branch |
| 4 | Separate observation/report/inference | Create 5-event timeline | Identify leading interview prompt |
| 5 | Define GDTA chain | Write L1/L2/L3 need for a single decision | Challenge current display assumption |
| 6 | Name ACTA's three interviews | Draft knowledge-audit probe | Identify invented expertise |
| 7 | Identify CDM decision point | Reconstruct competing options | Diagnose retrospective bias |
| 8 | Define means–ends | Make a 3-level abstraction hierarchy | Show what HTA cannot explain |
| 9 | Define source quality | Distinguish selected from actual state | Identify missing authoritative signal |
| 10 | List control-state stages | Draw inhibit transition | Find false acknowledgment |
| 11 | Differentiate error, hazard, workload | Write unsafe control scenario | Expose blame-centered explanation |
| 12 | Define requirement vs concept | Create two design alternatives | Show ungrounded numeric threshold |
| 13 | Define construct validity | Pick primary vs secondary metric | Explain misleading eye tracking |
| 14 | Define independent ground truth | Design deferred-mode comparison | Identify carryover/confound |
| 15 | Reliability vs validity | Propose blind coding | Challenge one agreement percentage |
| 16 | Define end-to-end trace | Defend design-to-test claim | State strongest disconfirmation |

**Scoring recommendation:** 0 absent/incorrect, 1 partially correct, 2 defensible, 3 defensible with source limits and counterexample. 9 possible weekly points; do not treat as a validated examination. Require remediation when a critical command-state or safety inference is wrong even with a high total.
