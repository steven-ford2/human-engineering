## Example online task sequence

1. Present synthetic display vignette without explaining the correct answer.
2. Ask the respondent to identify the displayed state (score objectively).
3. Ask what the system will do next if no input occurs (score objectively).
4. Record confidence as probability 0–100%.
5. Ask single post-task ease rating; preserve chosen scale wording and direction.
6. Counterbalance interface version and equivalent task items.
7. Collect direct paired design preference only after all objective responses.
8. Provide debrief and state clearly that scenario is synthetic.
